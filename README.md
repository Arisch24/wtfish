# wtfish

Fish identification app.

## Apps

- [`apps/web`](apps/web) — Astro web app (SEO/marketing/species pages). See its README for setup.

## Commits

Commit messages follow [Conventional Commits](https://www.conventionalcommits.org) (e.g. `feat(web): add species page`), enforced by commitlint via a husky `commit-msg` hook. Run `pnpm install` at the repo root once after cloning to install the hook.
